# Stack technologiczny dla HealthyMeal MVP

## Frontend
- **React** - biblioteka JavaScript do budowania interfejsu użytkownika
- **Bootstrap** - framework CSS dla responsywnego designu

## Backend
- **.NET 9** - framework do budowy API

## Baza danych
- **PostgreSQL** - relacyjna baza danych open-source
- **Azure Database for PostgreSQL** - zarządzana usługa bazodanowa w chmurze Azure

## AI
- **OpenAI API** - integracja z ChatGPT do modyfikacji przepisów
- **Azure OpenAI Service** (opcjonalnie) - dla lepszej kontroli kosztów i wydajności

## CI/CD
- **GitHub Actions** - automatyzacja procesu budowy i wdrożenia
- **Docker** - konteneryzacja aplikacji dla spójnych wdrożeń

## Hosting
- **Azure App Service** - hosting aplikacji webowej

## Bezpieczeństwo
- **Azure Key Vault** - bezpieczne przechowywanie kluczy API i innych wrażliwych danych
- **OAuth 2.0** - standard autentykacji dla logowania przez Facebook, Apple, Microsoft


## Zarządzanie projektem
- **GitHub** - repozytorium kodu i zarządzanie wersjami
- **GitHub Issues** - śledzenie zadań i błędów
- **GitHub Project Boards** - zarządzanie sprintami i workflow

## Monitorowanie
- **Application Insights** - monitorowanie wydajności i użycia
